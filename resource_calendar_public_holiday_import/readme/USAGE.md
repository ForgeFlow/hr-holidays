Go to *Time Off > Public Holidays*, click *Import*, choose the provider, the
country and the year, and click *Import*. Optionally set a *Subdivision*
(ISO 3166-2 code, e.g. `ES-CT`) to import only that region's holidays instead
of the whole country.

Holidays are created as global *Time Off* records. Non-national holidays get
their subdivision codes appended to the name (e.g. `Sant Joan [ES-CT]`).
